## 4. バージョン管理の決定

採用時にはPython依存lock、Hermes版、OpenJev commit/コンテナdigest、推論サーバー版、モデルrevision・量子化、質問定義、戦略設定、評価設定をそれぞれ固定する。将来更新は新しい組合せとして契約・回帰・品質試験を行う。型が互換でも判定確率が同じ意味・精度になると仮定しない。

外部資料に書かれたベンチマーク、処理速度、必要VRAMを本プロジェクトの測定値として記録しない。測定未了の項目には未測定と明記する。
